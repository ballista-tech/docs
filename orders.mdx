---
title: "Post Orders"
api: "POST https://api-staging.archer.exchange/v1/orders/build"
description: "Build an unsigned Solana transactions for a market swap. The client must sign and submit the returned transaction."
---

<Tip>
  For async/hybrid markets, the response includes an `intentId` that can be polled via `GET /v1/intents/{intentId}`to track execution.
</Tip>

#### **Flow:**

1. Call GET /v1/quote to preview the trade.
2. Call POST /v1/orders/build to get the unsigned transaction.
3. Sign the transaction with the user's wallet.
4. Submit the signed transaction to Solana.
5. (Async orders only) Poll GET /v1/intents/{intentId} for fill status.

<RequestExample>

```bash Request
curl -X 'POST' \
  'https://api-staging.archer.exchange/v1/orders/build' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "market": "string",
  "maxSlippageBps": 0,
  "orderType": "sync",
  "side": "buy",
  "size": "string",
  "swapMode": "MaxAmountIn",
  "takerAddress": "string"
}'
```

</RequestExample>
