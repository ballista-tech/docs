---
title: "Post Limit Order"
api: "POST https://api-staging.archer.exchange/v1/order/limit"
description: "Place a limit order"
---

Builds an unsigned tx that places a resting order on the owner's maker book (auto-funds collateral). The order exists only once the owner signs and that tx lands on-chain.

<RequestExample>

```bash Request
curl -X 'POST' \
  'https://api-staging.archer.exchange/v1/order/limit' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "market": "So11111111111111111111111111111111111111112",
  "owner": "Fg6PaFpoGXkYsidMpWxTWqLBeNmxVUFy8a3qFqkU2hwk",
  "price": "150.00",
  "side": "buy",
  "size": "1.5"
}'
```

</RequestExample>

<ResponseExample>

```json 200
// Unsigned transaction built.
{
  "addressLookupTables": [
    "string"
  ],
  "anchorMidTicks": 0,
  "depositBaseLots": 0,
  "depositQuoteLots": 0,
  "expiresAt": 0,
  "includesDeposit": true,
  "nextSequenceNumber": 0,
  "orderIds": [
    "string"
  ],
  "transaction": "string"
}
```

```json 400
//	Invalid parameters (bad price/size, crossed/full book, 16-level cap, etc.).
{
  "error": "INVALID_PARAMS",
  "message": "string"
}
```

```json 401
//Missing or invalid API key.
{
  "error": "INVALID_PARAMS",
  "message": "string"
}
```

```json 404
//Maker book or order not found.
{
  "error": "INVALID_PARAMS",
  "message": "string"
}
```

</ResponseExample>
