---
title: "Modify Limit Order"
api: "PUT https://api-staging.archer.exchange/v1/order/limit"
description: "Modify a limit order"
---

Resize keeps the order id; a price change is cancel\+place and yields a new id.

<RequestExample>

```bash Request
curl -X 'PUT' \
  'https://api-staging.archer.exchange/v1/order/limit' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "newPrice": "151.25",
  "newSize": "2.0",
  "orderId": "string"
}'
```

</RequestExample>

<ResponseExample>

```json 200
// Unsigned transaction built.
{
```
