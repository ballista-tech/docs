---
title: "Get Market Details"
api: "GET https://api-staging.archer.exchange/v1/markets/{address}"
description: "Returns the configuration and metadata for a single market."
---

<RequestExample>

```bash Request
curl -X 'GET' \
  'https://api.archer.exchange/v1/markets/A7Zx9dfLuZmdXJjdfakwLbnPmeHE8L28Nf5D2buCCFNq' \
  -H 'accept: application/json'
```

</RequestExample>

#### Query Parameters

<ParamField path="address" type="string" required>
  Base58-encoded Solana address of the market.

  Example: `5Ggx...abc`
</ParamField>
