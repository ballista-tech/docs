Archer Trading API offers a performant interface to interact with Archer, a fully on-chain order book exchange on Solana. We offer a REST API interface to access data on markets, perform swaps, trade with limit orders, and manage deposits/withdrawals. We also provide a websocket interface to stream live market data.

Archer Trading API is currently in Private Beta. For interacting with the API, you will need an API key. For request to access, please DM us [here](https://t.me/mmdhrumil).
