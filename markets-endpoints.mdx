title: "Get Markets"

<RequestExample>

```bash Request
curl -X 'GET' \
  'https://api.archer.exchange/v1/markets?quote=USDC&base=SOL&sort=address&order=asc&limit=50&offset=0' \
  -H 'accept: application/json'
```

#### Query Parameters

<ParamField query="type" type="string">
  Filter by market type.

  Available options: `continuous`, `async`, `hybrid`
</ParamField>

<ParamField query="status" type="string">
  Filter by market status.

  Available options: `active`, `paused`
</ParamField>

<ParamField query="quote" type="string">
  Filter by quote token symbol (case-insensitive).

  Example: `USDC`
</ParamField>

<ParamField query="base" type="string">
  Filter by base token symbol (case-insensitive).

  Example: `SOL`
</ParamField>

<ParamField query="search" type="string">
  Free-text search across token symbols, names, mints, and market addresses.
</ParamField>

<ParamField query="sort" default="address" type="string">
  Sort field.

  Available options: `address`, `baseSymbol`, `status`, `volume24h`
</ParamField>

<ParamField query="order" default="asc" type="string">
  Sort direction.

  Available options: `asc`, `desc`

  Default value: `asc`
</ParamField>

<ParamField query="limit" default="50" type="integer">
  Maximum number of results to return.

  Default value: 50
</ParamField>

<ParamField query="offset" default="0" type="integer">
  Number of results to skip (for pagination).

  Default value: 0
</ParamField>
