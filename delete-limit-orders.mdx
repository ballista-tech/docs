---
title: "Cancel Limit Order"
api: "DELETE https://api-staging.archer.exchange/v1/order/limit"
description: "Cance a limit order (one or all)"
---

Cancel a single order by id, or all of the owner's orders on a market (all=true).

<RequestExample>

```bash Request
curl -X 'DELETE' \
  'https://api-staging.archer.exchange/v1/order/limit' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "all": false,
  "market": "string",
  "orderId": "string",
  "owner": "string"
}'
```

</RequestExample>
