---
title: "Post Market Order"
api: "POST https://api-staging.archer.exchange/v1/order/market"
description: "Build a market (swap) order"
---

Alias of POST /v1/orders/build under the unified /order namespace.

<RequestExample>

```bash Request
curl -X 'POST' \
  'https://api-staging.archer.exchange/v1/order/market' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "market": "string",
  "maxSlippageBps": 0,
  "orderType": "sync",
  "side": "buy",
  "size": "string",
  "swapMode": "MaxAmountIn",
  "takerAddress": "string"
}'
```

</RequestExample>

{
